# Sponsoring repoDocs

**repoDocs is free and open source (MIT)** — no artificial limits, no sign-up wall. Sponsoring is
how the project keeps moving: every contribution directly funds the roadmap items labeled
[`funded`](https://github.com/alecerca/repoDocs/labels/funded) and keeps the maintainer able to
answer issues properly.

## Tiers

| Tier         | Price   | What you get                                                                 |
| ------------ | ------- | ---------------------------------------------------------------------------- |
| ☕ **Coffee**   | $3/mo   | Vote on roadmap priorities, thank-you on the sponsor wall                     |
| 🚀 **Supporter** | $8/mo   | Everything above, **plus** prioritized issue requests (your bugs/features go first) |
| 🏢 **Studio**   | $20/mo  | Office/team support: onboarding call, priority reviews, roadmap input for your setup |

## Where the money goes

Tiers accumulate toward a monthly pool that funds the `funded` roadmap issues, in order of votes:

- **[#6 Plugin system](https://github.com/alecerca/repoDocs/issues/6)** — custom importers/exporters
  (frontmatter, custom tables, dialects).
- **[#5 Canvas export](https://github.com/alecerca/repoDocs/issues/5)** — export the canvas layout
  as PNG / shareable link.
- **[#4 GitHub integration](https://github.com/alecerca/repoDocs/issues/4)** — pull & push `.md`
  to a remote repo as commits/PRs.

Voting happens via reactions/comments on the issues — as a **Coffee+** sponsor your vote weighs double.

## FAQ

**Why subscribe instead of a one-time donation?**
A subscription is predictable: it lets me reserve real time for the funded issues instead of
squeezing it in between other work.

**Can I cancel anytime?**
Yes. You can cancel or change tiers at any time from your GitHub Sponsors dashboard.

**Do I get private code or support?**
Support is public unless you pick **Studio**. There is no private branch — repoDocs stays MIT.
