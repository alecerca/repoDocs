# repoDocs

Canvas: export layout as PNG / shareable link

## Overview

**Contexto:** la vista canvas es libre (arrastrar cards, fit view).
**Propuesta:** exportar la composición a PNG y codificar el layout en un link para compartir.
**Por qué es "fundable":** es el diferenciador "Figma-like" que más llama en Show HN.

## Installation

```bash
# Clone the repository
git clone https://github.com/alecerca/repoDocs.git
cd repoDocs

# Install dependencies (if applicable)
pip install -r requirements.txt  # Python
# or
npm install  # Node.js
```

## Usage

```bash
# Run the project
python main.py  # Python
# or
node index.js  # Node.js
```
