# 0005. Live previews in the editing experience

## Context

Editing raw Markdown is fine for power users, but contributors without Markdown muscle benefit from
seeing the rendered outcome while they type.

## Decision

Open a proposal: add rich live previews (formatting toolbar, rendered preview panel) to every
edit flow, and per-decision visual badges in the board.

## Consequences

- Lower barrier for non-technical contributors.
- Riskier: more UI surface to maintain; must keep write-back untouched.
- Currently proposed — revisit and either accept or reject before shipping.
